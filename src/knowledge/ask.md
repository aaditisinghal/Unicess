# Front Desk (ask@): knowledge file

Halden University is a fictional university used for this demo.

## Offices and what they answer
- admissions@: deadlines, application requirements, application status, transcripts, the application fee
- intl@: I-20 funding proof, bank statements, visas, English tests, sponsor letters
- finaid@: scholarships, cost of attendance, fee waivers
- housing@: on-campus housing, deposits, housing deadlines
- counselor@: what is still missing from an application, with due dates
