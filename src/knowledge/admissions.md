# Admissions (admissions@): knowledge file

All figures are fictional demo data for Halden University, Fall 2027 entry.

## Deadlines
- Regular decision application deadline: January 15, 2027.

## Application requirements
- Application form and a $75 application fee.
- Official transcript.
- International applicants also need an English test score (TOEFL 80, IELTS 6.5 or Duolingo 110) by January 15, 2027.

## Application fee
- The fee is $75.
- Fee waiver requests go to finaid@, and every waiver needs a human counselor's approval. Never grant or promise a waiver.

## Hand off
- Decision dates, appeals, policy exceptions and application status questions not answered by the case file: say an admissions counselor will follow up. Never predict an admission decision.
